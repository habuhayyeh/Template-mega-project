# P003 — three Doximity runs, corrected evidence boundary

**Corrected after `reviews/P003-implementation-doximity-original-branch.md`.** The first version of this file scored three runs as one reproducibility set. They were not one set, and one of its findings was unmeasurable.

## The three files are not three repetitions

- `run1.txt` — **no dispatcher**. The model was given the files and told nothing. This is a control for an under-specified call, not a member of the P003 reproducibility set.
- `run2.txt`, `run3.txt` — dispatcher: read `05`, then `AP_ANCHOR`, apply to the Handoff, add nothing, return only the A/P.

A reproducibility set needs identical conditions. The valid set here is two runs, and two cannot establish stability. **No canonical Doximity reproducibility measurement exists yet.**

## What run1 does and does not prove

It produced `postictal confusion resolved` on the problem line. No object supports resolution; O6 says the confusion lasted an hour.

- It **does** prove an under-specified Doximity call will invent a clinical status.
- It **does not** prove the dispatcher-qualified `05` fabricates. Runs 2 and 3 did not.

That distinction is the difference between "the contract fails" and "the package matters".

## What is not a finding at all

**`Seizure precautions` missing from all three runs is not a runtime failure.** The package given to Doximity contained `05_WRITE_AP.md`, `AP_ANCHOR.md` and `handoff.txt`. It did not contain `STANDING_ITEMS.md`, and the item's text does not appear inside `05`. The stage could not have rendered it. That was a test-packaging defect; the standing-item rule is untested.

## The D-014 contradiction is upstream, not in `05`

`05` says the Handoff is the whole population. The frozen Handoff contains O54. D-014 says O54 must not appear in the A/P. Both cannot be true.

`05` does not read `DECISIONS.md`, and under D-002 it should not go looking for hidden exclusions. So the fix is upstream: the baseline A/P input must not offer O54 at all. Adding a D-014 exception sentence to `05` would put a permanent clinical decision inside a formatting stage.

## Verdict

**FAILED for the dispatcher-qualified runs.** Not "pending". The implemented stage has produced unacceptable output under the intended conditions.

No canonical three-run measurement exists yet, and none can exist until the package is complete and the baseline input is consistent.

## Required next state

1. Baseline A/P input excludes O54 upstream, so D-014 is represented by absence rather than by a rule in `05`.
2. Canonical package: `05_WRITE_AP.md`, `AP_ANCHOR.md`, `STANDING_ITEMS.md`, frozen Handoff, one dispatcher, unchanged across runs.
3. Fail-only checker proposal for the mechanically enforceable invariants.
4. Then three fresh Doximity runs under identical conditions.
