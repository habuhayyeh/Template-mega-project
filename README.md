# Template-mega-project

Doximity neurology note-generation system: source-faithful body, concise neurologic A/P, one shared semantic substrate.

Read in this order:

1. `AGENTS.md` — roles and the rules of collaboration
2. `STATUS.md` — what is current, and which files are canonical
3. `DECISIONS.md` — what is settled
4. `PROJECT.md` — what is being built

Then `pipeline/` for the stages, `substrate/` and `oracles/` for the accepted state.
